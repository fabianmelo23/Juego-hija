# Casa de Gatos

Juego Android de cuidadora de gatos.  
**Dirección visual actual:** habitación **isométrica** personalizable.

## Plan isométrico

Catálogo y orden de creación: [`docs/ISO-ROOM-DIRECTOR.md`](docs/ISO-ROOM-DIRECTOR.md)

### Estado
- ✅ **Ítem 01 — Piso base** (madera clara / cálida / azul suave)
- ✅ **Ítem 02 — Pared izquierda** (crema / rubor / salvia)
- ✅ **Ítem 03 — Pared derecha** (crema / rubor / salvia) — shell completo
- ✅ **Ítem 07 — Ventana pequeña** (Día / Tarde / Noche)
- ✅ **Ítem 11 — Lámpara de techo** (Cálida / Rosa / Apagada)
- ✅ **Ítem 04 — Papel tapiz** (Ninguno / Puntos / Rayas)
- ✅ **Ítem 15 — Alfombra chica** (Ninguna / Rubor / Salvia / Cielo)
- ✅ **Ítem 19 — Cama de gato** (Ninguna / Crema / Rubor / Menta)
- ✅ **Ítem 20 — Plato de comida** (Ninguno / Lleno / Medio / Vacío)
- ✅ **Ítem 22 — Rascador** (Ninguno / Madera / Rubor / Menta)
- ✅ **Ítem 24 — Pelota** (Ninguna / Roja / Cielo / Sol)
- ✅ **Miel + cuidados** en el cuarto iso (Cuidar / Misión / Tienda)
- ✅ **Colocación libre** en el grid (mover muebles tocando el piso)
